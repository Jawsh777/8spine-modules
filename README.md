# 8spine Modules

Typescript plugins for the 8spine music streaming application.

## Building Modules

```bash
# Install dependencies
npm install

# Build all modules (src/* -> dist/*.8spine)
npm run build

# Watch mode - auto-rebuild on file changes
npm run build:watch

# Minfied build
npm run build:minify
```

## Directory Structure

- `src/` - Source Typescript files for modules
- `dist/` - Built .8spine files (generated by build)
- `scripts/` - Build tooling
- `tests/` - Module, Javascript and build script tests
- `types/` - Types used across modules
